MEDIA HUB - qué hay en esta carpeta

1) MediaHub-1.0.0-portable.exe   -> Aplicación de Windows. Doble clic, sin instalar.
                                    Se entrega en trozos (MediaHub-parte.0 ... .4) por su tamaño (107 MB):
                                    ponlos junto a unir-exe.bat y haz doble clic en unir-exe.bat.
                                    (Si SmartScreen avisa: "Más información" > "Ejecutar de todas formas").
2) .env.example                  -> Copia este archivo como ".env" junto al .exe y pon tus claves gratuitas
                                    (TMDB para películas y series, Jamendo para música). Son opcionales.
3) web-estatica/                 -> La misma app como web (HTML/CSS/JS). Súbela a GitHub Pages, Netlify, etc.
                                    En local: abre una terminal en esa carpeta y ejecuta:  npx serve .
4) codigo-fuente/                -> Proyecto completo para modificar y compilar (npm install, npm start, npm run dist:win).
5) opcional-servidor-docker/     -> Alternativa con Jellyfin, Navidrome y Audiobookshelf para tus propios archivos.
6) LEEME.md                      -> Documentación completa.
